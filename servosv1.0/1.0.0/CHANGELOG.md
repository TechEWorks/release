# ServOS 1.0.0 release notes

Released 2026.11.05.

- Public network ISO and buildable source snapshot for the standalone minimal
  Debian 13.7 server foundation.
- Text installer with DHCP or static IPv4, disk identity review, valid storage
  choices for selected disk count, password or public-key SSH access, typed
  erase confirmation, visible install tasks and a saved log.
- Boot and interactive SSH show the shared system, network, capacity, storage,
  GPU and package-command summary.
- Product wording consistently names **TechE ServOS** as the installed OS.
  **DriveOS** names its selected OS disk or disk set.
- Shared TechE licensing and IP standards dated 2026.11.05; ServOS source
  adopts AGPL-3.0-only. Upstream components keep their own terms.

The [QA record](QA.md) distinguishes passed source/build checks and earlier
backend live tests from checks still open for this exact ISO. The WorkDesk
catalog is not configured until its public pinned asset is published.
