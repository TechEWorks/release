# ServOS Production evaluation — public repository mirror

This directory is a **source-controlled mirror of the local release-content evaluation**, not a Production gate decision or a replacement GitHub Release asset. The original 242-file local evaluation ZIP (SHA-256 `d1b4f883b2f8eff989c3f3660d2812641e0d6239e369e382ea6d3069e72f5e6b`) contains 26 captures. Nine were excluded from the current 17-screen public gallery because they showed QA network addresses. That ZIP is retained as a local audit input and is **not approved for publication**; a publishable packet needs curation, a new hash and review. This repository mirror omits its large binary ISO, pinned base ISO and one-ISO transport to avoid committing duplicate release binaries to Git. Obtain the unchanged published ISO from the [existing GitHub release](https://github.com/TechEWorks/release/releases/tag/servosv1.0-v1.0.0), SHA-256 `b449436c0575a0dd95d61a3a228b0cbe465f415b64dea392352b1da2c04556cf`.

The 17-image gallery selection does not remove historical public screenshots. At release-repository commit `f2ebe17`, 48 other ServOS image paths were still tracked; eight of those paths were byte-identical to four captures excluded from the current gallery. Those existing routes and older Git revisions remain public. Review and correction of those routes is open; gallery curation alone is not a privacy or publication clearance.

The original local packet's verification script, checksum list and manifest are retained with that packet; this public Git mirror intentionally omits them and the large binaries. The [delivery route](DELIVERY-ROUTE.md) identifies the current public release, the proposed 06 Production evaluation, and the still-open decisions. The [rights packet](RIGHTS-DECISION-PACKET.md) keeps unresolved evidence explicit.

This mirror preserves the front page, [17-screen gallery](gallery/README.md), exact ISO component inventory, source reconciliation, human/AI instructions, Business and QA crosswalk, issue register, and historical ServOS documentation snapshot for review. The complete original [source ZIP](https://github.com/TechEWorks/release/releases/download/servosv1.0-v1.0.0/TechE-ServOS-13.7-v1.0-SOURCE.zip) remains at its existing release URL. No new ISO was built or uploaded.
