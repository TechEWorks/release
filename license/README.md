# TechEWorks software licensing

Revision: 2026.11.05. See [change history](CHANGELOG.md).

This folder holds the default license text and licensing rules for public
TechEWorks software. A product adopts a license through its own release record
and a `LICENSE.txt` shipped with its source. This folder alone does not relicense
an unpublished product or any third-party component.

The default for TechE-owned OS product code is
[AGPL-3.0-only](LICENSE-2026.11.05.txt) when TechE has the rights needed to grant it.
The product record identifies the covered files, corresponding source, upstream
components, notices and any exception. Independent recipients keep the rights
given by the applicable license; TechE certification and services are separate.

Debian, firmware, tools, fonts and other upstream materials retain their own
licenses. Each public product release must carry its own `LICENSE.txt`, a
third-party notice, exact source and binary identities, and any required
upstream license material. Do not copy a license label onto code TechE does not
own or have permission to license.

The policy is based on TechE's *OS Licensing Decision Process and Alpha
Recommendation*, version 1.1, dated 27 October 2026. Product-specific release
clearance and notices remain required. See the
[shared IP policy](https://github.com/TechEWorks/release/blob/main/ip/README.md).
