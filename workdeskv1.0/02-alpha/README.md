**Alpha users** may evaluate the expressly designated QA previews under their stated safety limitations. **Alpha testers** must use the exact asset hash and execute independent route/install/installed-system QA; tests do not transfer to Beta or another output. Both audiences must observe distribution and applicable rights restrictions. Public URLs are accessible to anyone; they are **not** authorization controls.

Assets can be ISOs, root images, configuration archives, Calamares packages, checksums, scripts, fonts or other necessary files. Later stages pin the producer asset ID and digest, independently verify it, then execute their own tests. Existing legacy native artifacts remain indexed honestly; new artifacts use S4's single lossless ZIP transfer, with the native file AND ZIP strictly less than 2,000,000,000 decimal bytes, no multipart. Private/unapproved candidate records and QA remain in Alpha, while restricted files require authenticated distribution.

**The WorkDesk official approved-release index currently has no approved releases.** Existing QA previews are not promoted by creation of this stage catalog.
